This is a list of things you should've checked before you run the main python program

In iwr1642_live.py:
1. Check or change the config (.cfg) file in folder named "configs". It is in CFG_FILE variable
2. Check or change the COM numbers in CLI_PORT and DATA_PORT variables

In fusion-python-3.10.py:
1. Check or change the YOLO model for your camera. It is in DETECTOR variable
2. Check differences in position and angle 
3. Camera index

Run it with command:
python fusion-python-3.10.py
