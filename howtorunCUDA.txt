Open python file, write, and run:
import torch
print(torch.cuda.is_available())

if TRUE: Python is connected to CUDA and YOLO will use dedicated GPU instead of CPU.

if FALSE: You need to install torch and its dependencies.
  write to terminal:
    pip uninstall torch torchvision torchaudio -y
  and then, write to terminal: 
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
  you may open a python file and check the torch is available or not.

This note was made for Python 3.9.
