This is a list of things you should've checked before you run the main python program

Read/edit the configs.json:
1. RADAR_CONFIGS: Check or change the config (.cfg) file in folder named "radar_configs"
2. CLI_PORT and DATA_PORT: Check or change the COM numbers in CLI_PORT and DATA_PORT variables, default is COM6 and COM7
3. DETECTOR: Check or change the YOLO model for your camera. Default is yolo-world
4. CAMERA_INDEX: 1 is USB, 0 is built-in camera

Check iwr1642_live.py:
1. Check differences in position and angle 

Run it with command:
python fusion-python-3.10.py
